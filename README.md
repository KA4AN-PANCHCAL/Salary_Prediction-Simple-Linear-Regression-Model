💸 Salary Prediction Model (Simple Linear Regression)


📌 Project Overview

A machine learning model designed to predict the salary package of an individual based on their years of professional experience. This project demonstrates the fundamental concepts of Simple Linear Regression and data visualization.



🛠️ Tech Stack


Language: PythonLibraries: Pandas, NumPy, Scikit-Learn (ML), Matplotlib (Visualization)



🚀 Key FeaturesData 

Splitting: 80/20 Train-Test split for unbiased evaluation.

Model Training: Implemented a LinearRegression model from Scikit-Learn.



Accuracy: Evaluated the performance using the $R^2$ Score.



Visualization: Includes a scatter plot comparing actual data vs. the model's prediction line.





📊 Results


The model successfully identifies the linear relationship between experience and income.


Metric: $R^2$ Score.



Insight: As experience increases, the predicted package follows a clear upward trend.
